# Tunnelka

Простой VPN-клиент для Windows. Добавляешь ключ, выбираешь сервер, нажимаешь одну кнопку.

В основе — [Xray-core](https://github.com/XTLS/Xray-core) и [sing-box](https://github.com/SagerNet/sing-box).

## Скачать

**[⬇️ Скачать Tunnelka для Windows](https://github.com/swagmachine999/tunnelka_proxy/releases/latest)**

На открывшейся странице внизу, в блоке **Assets**, два файла на выбор:

- `Tunnelka-Setup-….exe` — установщик. Подходит большинству: ярлык в меню «Пуск», автообновление, режим TUN без запроса прав при каждом подключении.
- `Tunnelka-….zip` — портативная версия. Распакуй в любую папку и запусти `Tunnelka.exe`. Ничего не устанавливается, но для режима TUN Windows будет спрашивать права администратора.

## Установка

1. Запусти `Tunnelka-Setup-….exe`.
2. Если Windows покажет «Система Windows защитила ваш компьютер», нажми «Подробнее», затем «Выполнить в любом случае». Так бывает, потому что у программы пока нет цифровой подписи.
3. Разреши установку, когда Windows спросит про права администратора. Это нужно один раз.
4. По желанию отметь «Запускать вместе с Windows».
5. Нажми «Установить».

Ярлык появится в меню «Пуск».

## Как пользоваться

1. Получи ключ у своего VPN-сервиса. Обычно его присылает Telegram-бот или он есть в личном кабинете на сайте.
2. Нажми «Вставить ключ», «+» или Ctrl+V. Если ключ показан QR-кодом — «Сканировать QR».
3. Выбери сервер или «⚡ Авто» и нажми большую круглую кнопку.

## Режимы

- **Прокси** — работает без прав администратора. Трафик идёт через VPN у программ, которые используют системный прокси.
- **TUN** — весь трафик компьютера, включая игры и программы без настроек прокси. Нужны права администратора: при установке через установщик они запрашиваются один раз, у портативной версии — при каждом подключении.

## Возможности

- Ключи vless, vmess, trojan, shadowsocks и подписки по ссылке
- «⚡ Авто» в каждой подписке — самый быстрый сервер этого провайдера
- Быстрый и реальный пинг серверов
- Обновление подписки одной кнопкой: галочка, если всё хорошо, и причина, если не получилось
- Добавление ключей через QR-код
- Маршрутизация: список программ и сайтов, у каждого переключатель VPN / ПРЯМОЕ. Режимы «VPN для выбранных» и «Прямое для выбранных»
- Статистика трафика за разные периоды
- Оверлей поверх игр и окон по горячей клавише (по умолчанию Ctrl+Alt+P): пинг, скорость и потеря пакетов. Потеря пакетов включается в настройках оверлея
- Предупреждение, когда подписка скоро закончится
- Запуск вместе с Windows и автоподключение
- Автообновление приложения
- Светлая и тёмная тема, русский и английский язык
- Масштаб интерфейса от 50% до 200%: меняется ползунком сразу, без перезапуска и без разрыва подключения

## Обновления

Приложение само проверяет новые версии. Когда выходит обновление, появляется окно «Доступна новая версия» — нажми «Да», и оно скачается и установится. Проверить вручную можно в разделе «О приложении» (значок ⓘ слева внизу).

## Системные требования

- Windows 10 или 11, 64-бит
- Процессор x64 (Intel или AMD)
- Около 300 МБ на диске и 300 МБ свободной памяти
- Экран от 1280×720
