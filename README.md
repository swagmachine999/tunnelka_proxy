# Tunnelka

Простой VPN-клиент для Windows на основе [Xray-core](https://github.com/XTLS/Xray-core) и [sing-box](https://github.com/SagerNet/sing-box). Добавляешь ключ, выбираешь сервер, нажимаешь одну кнопку.

## Скачать

**[⬇️ Скачать Tunnelka для Windows](https://github.com/swagmachine999/tunnelka_proxy/releases/latest)**

На открывшейся странице внизу, в блоке **Assets**, нажми `Tunnelka-Setup-….exe`.

## Установка

1. Запусти скачанный `Tunnelka-Setup-….exe`.
2. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажми «Подробнее», затем «Выполнить в любом случае». Так бывает, потому что у программы пока нет цифровой подписи.
3. По желанию отметь галочки:
   - «Запускать вместе с Windows»;
   - «Очистить кэш» — ключи и настройки при этом сохраняются.
4. Нажми «Установить».

Права администратора для установки не нужны. Ярлык появится в меню «Пуск».

## Обновления

Приложение само проверяет новые версии. Когда выходит обновление, появляется окно «Доступна новая версия» — нажми «Да», и оно скачается и установится. Проверить вручную можно в разделе «О приложении» (значок ⓘ слева внизу).

## Системные требования

- Windows 10 или 11, 64-бит
- Процессор x64 (Intel или AMD)
- Около 300 МБ на диске и 300 МБ свободной памяти
- Экран от 1280×720
- Права администратора нужны только для режима TUN

## Как пользоваться

1. Получи ключ у своего VPN-сервиса. Обычно его присылает Telegram-бот или он есть в личном кабинете на сайте.
2. Нажми «Вставить ключ», «+» или Ctrl+V. Если ключ показан QR-кодом — «Сканировать QR».
3. Выбери сервер или «⚡ Авто» и нажми большую круглую кнопку.

Для режима TUN приложение само предложит перезапуститься с правами администратора.

## Возможности

- Ключи vless, vmess, trojan, shadowsocks и подписки по ссылке
- «⚡ Авто» в каждой подписке — самый быстрый сервер этого провайдера
- Режимы «Прокси» и TUN (весь трафик компьютера)
- Реальный и быстрый пинг серверов
- Обновление подписки одной кнопкой: галочка, если всё хорошо, и причина, если не получилось
- Добавление и отправка ключей через QR-код
- Маршрутизация: сайты и программы напрямую, через VPN или в блок
- Статистика трафика за разные периоды
- Оверлей поверх игр и окон: пинг, скорость и потери по горячей клавише (по умолчанию Ctrl+Alt+P)
- Предупреждение, когда подписка скоро закончится
- Запуск вместе с Windows и автоподключение
- Автообновление приложения
- Светлая и тёмная тема, масштаб, русский и английский язык

## Где хранятся данные

Ключи и настройки лежат в папке `%LOCALAPPDATA%\Tunnelka` в файле `data.dat`. Файл зашифрован средствами Windows: прочитать его может только тот же пользователь на том же компьютере. При обновлении и переустановке данные сохраняются.

Если приложение упадёт, причина запишется в `crash.log` в той же папке.

## Сборка из исходников

1. Установи [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
2. Создай в корне проекта папку `core` и положи в неё:
   - `xray.exe`, `geoip.dat` и `geosite.dat` из архива `Xray-windows-64.zip` ([релизы Xray](https://github.com/XTLS/Xray-core/releases));
   - `sing-box.exe` и `libcronet.dll` из архива `sing-box-…-windows-amd64.zip` ([релизы sing-box](https://github.com/SagerNet/sing-box/releases)).
3. Выполни в папке проекта:
   ```
   dotnet run
   ```

Установщик и архив собирает GitHub Actions при каждом пуше. Чтобы выпустить релиз, поставь тег вида `v1.0.3` — сборка сама создаст релиз с установщиком.
